# Tartil

Mədəni səhifə. Mikrofon açılanda ayələr gizlənir. Oxuduqca sözlər təxminən 1–2 saniyə gecikmə ilə ekrana qayıdır.

Tanıma telefonda, açıq mənbə [Tilawa](https://github.com/yazinsai/tilawa) Zipformer modeli ilə gedir. Model və lüğət **NPL-1.2** (qeyri-kommersiya) — bax `NOTICE.md`.

Bu depo ayrıca durur. Başqa sayta bağlanmayıb.
